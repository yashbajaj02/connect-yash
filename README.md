# Connect — Developer Portfolio & Hub

A premium, responsive developer portfolio and personal hub built to showcase projects, skills, experience, and ways to connect with Yash Bajaj.

## ✨ Highlights

- Responsive, mobile-first portfolio experience
- Project showcase with structured project information
- Smooth UI animations and interactions
- Contact and social links
- Modern developer-focused design
- Vercel-ready deployment configuration

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React
- Vercel

## 🚀 Getting Started

```bash
git clone https://github.com/yashbajaj02/connect-yash.git
cd connect-yash
npm install
npm run dev
```

Create your local environment from `.env.example` when required by the project configuration.

## 📦 Production Build

```bash
npm run build
npm run preview
```
